## 规则

- 保留现有机架、输出映射、正反转、舵机、档位、失联保护和解锁流程。
- 新参数`MOT_DZ_PWM`是两侧相同的PWM启转偏移，单位μs，范围0～100，
  固件默认0（关闭），参考启用值50，不是“实测保证转动”或90%推力修正。
- 新参数`MOT_DZ_IN`是混控后归一化输出的小输入死区，范围0～0.1，默认0.01。
  仅补偿启用时有效，抑制接近零的纠偏噪声；不是手柄4%死区，也不是50μs电调死区。
- 补偿发生在混控与MOT_n_DIRECTION之后、正常PWM输出之前，覆盖全部启用电机及
  手柄/姿态/定深共同请求。相反控制分量应先相消，不能逐轴分别加启转偏移。
- 零请求和小输入死区保持1500。超过输入死区后，从±50附近连续增长到实际
  MOT_PWM_MIN/MAX。1000/2000范围内的剩余450μs映射到剩余输入行程，避免直接
  叠加50导致90%输入时就提前达到满量程。这不是缩小某一方向推力90%。
- 关闭补偿时恢复标准线性映射；±100%仍到实际端点。上锁、地面空闲输出仍保持1500。
- 原始DO_MOTOR_TEST输出不经过此转换，测试输入多少PWM就请求多少PWM；
  避免重复补偿或污染启转测量。实际输出需核对SERVO_OUTPUT_RAW。
- 异常非有限输入返回1500，幅度/偏移/输出边界受限；没有额外通信进程或输出线程。

启转存在最低非零输出，跨零时仍有跳变。死区过大可能降低定深/姿态精度，补偿过大
可能造成低速振荡；50μs和1%都需水下验证，不能据此宣称闭环稳定。并未加入输出斜率
限制、逐台推力曲线或反作用扭矩模型。
