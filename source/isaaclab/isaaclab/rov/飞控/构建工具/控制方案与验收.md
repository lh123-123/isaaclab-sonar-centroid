## 操作规则

| 操作 | STABILIZE / ALT_HOLD 中的行为 |
| --- | --- |
| 左摇杆 | 前后、左右平移；保留明确的斜向输入和原有正方向辅助 |
| 右摇杆上下 | 给出俯仰倾角；回中时目标平顺回到 0° |
| 横滚 | 当前没有手动横滚键位，持续自动回平；不会保持倾斜横滚角 |
| 右摇杆左右 | 转向；回中减速后捕获一次航向，随后抗扰保持该航向 |
| RT / LT | 上升 / 下潜；原有线性输入不变 |
| X | 独立开/关定深，保留Y姿态稳定状态；由飞控回传确认 |
| Y | 独立开/关姿态稳定，保留X定深状态；姿态关时没有回平/航向保持 |
| B | 立即上锁，保留现有最高优先级 |

MANUAL（模式 19）不提供上述自动回平/定深，不能将其当作 STABILIZE。
最新独立固件另有私有DepthOnly（模式22），只定深、不稳姿态；X/Y四种组合默认均关闭。
当前电脑运动输入及完整方向核对见 `../运动优化与方向核对_20261004.md`，水下稳定尚未验收。
这轮没有重新分配 M1–M4、LM/RM、LB、菜单键、云台或夹爪，也没有添加 R3 回平键。

## 分工和实现

PC 保留现有手柄输入、档位、解锁归中检查及舵机管理。树莓派仍只转发 MAVLink，
不增加另一套姿态 PID、不争抢串口。QGC 仍用于飞控模式、参数、告警和视频；
没有修改 QGC 可执行程序。PC 面板的“动力与转向回传”入口增加实测姿态及增强执行状态。

新飞控代码只在标准姿态/定深模式中整理目标角度，复用 ArduSub 的角度映射、
姿态角/角速度反馈及深度闭环。俯仰/横滚目标加入速度和加速度约束；目标/倾角边界
优先于轨迹连续性，边界处可截断速度。上锁清空目标，再次解锁从当前实测姿态开始
平顺回平。STABILIZE 与 ALT_HOLD 相互切换不突然重置姿态/航向目标；定深进入时仍
使用标准深度控制初始化。航向跨 ±180° 正确环绕，EKF 航向坐标重置同步更新目标。

新目标最大速率初始为倾角 30°/s、偏航 45°/s，目标加速度 90/120°/s²。
实际机体运动还受原有 ATC 角速度/加速度、PID、电源及推进器能力约束，不能把目标
斜率当作实测机体速度。全部新功能默认关闭，未启用时保留标准控制路径。

`MOT_ATT_PRIO=1` 对 FRAME_CONFIG=2 的两个独立推进器平面先保留旋转纠偏余量，
再统一缩放平移请求。斜向平移的比例不被单独剪切，电机输出不会越界；姿态或深度
请求饱和时向原控制器报告限幅，供其抗积分饱和使用。代价是大幅转向/回平时可以
减少行进、上升或下降推力，因此不是每种复合运动都让每台电机满输出。

现有物理/逻辑电机映射、正反桨及转向参数完全不改。保留全电机混控后的对称
50μs启转补偿，不加入未经水下标定的90%强弱推力曲线。

增强启用后，超过 `ROV_IN_TMO=0.35s` 没有手动控制更新，将缓存平移、升潜、转向
请求归零；俯仰/横滚仍回平，定深模式仍由飞控维护深度。原有失联上锁保护不关闭。
参数不合法时增强目标生成无效，回退标准姿态控制；失联时该回退也不会继续使用
缓存倾角/转向输入。外部有效 SET_ATTITUDE_TARGET 保留原有优先级，并清空手柄目标，
退出外部控制时重新平顺接管。

## 参考取舍

旧比赛工程的优点是连续输入、基于角速度的阻尼、抗积分饱和和稳定的 PC/Pi/下位机
职责边界；本次保留这些原则，不复制旧工程不同硬件上的 PID 数值、浮力学习值或
没有实测依据的推力模型。SJTU 的 50μs启转思路已经在混控后实现，不按每个输入轴
重复叠加。官方参考：

- [ArduSub pilot control](https://ardupilot.org/sub/docs/pilot-control.html)：倾角输入、偏航速率和定深模式分工。
- [固定基线标准姿态模式](https://github.com/ArduPilot/ardupilot/blob/dbe792162d06cab66c3475fd5556bf7a120f119e/ArduSub/mode_stabilize.cpp)。
- [固定基线标准定深模式](https://github.com/ArduPilot/ardupilot/blob/dbe792162d06cab66c3475fd5556bf7a120f119e/ArduSub/mode_althold.cpp)。
- [官方手动整定说明](https://ardupilot.org/sub/docs/manual-tuning.html)：PID 必须根据实际水下响应整定。
