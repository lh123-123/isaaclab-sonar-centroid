# 夹爪角度控制说明

## 按键行为

- 主 GUI `pc_gui.py` 使用 RB/R1 控制夹爪瞬时开合。
- 当前关闭位置：以 `config.ini` 的 RB 关输入为准（当前为 `10° / 1056 us`，归一化位置约 `0.0556`）。
- 第一次按下 RB：夹爪瞬时打开到 `120° / 1667 us`。
- 第二次按下 RB：夹爪瞬时关闭到 `20° / 1111 us`。
- 只识别按下沿，长按不会在 40 Hz 循环中反复开合。
- 按住 R3 缓慢增大角度，按住 L3 缓慢减小角度。
- 急停期间忽略夹爪切换；急停或失联回到关闭位置后，下一次有效按下从“打开”开始。

## 配置

在 `config.ini` 的 `[servo]` 段中：

```ini
toggle_button = 10
open_position = 0.6666666666666666
closed_position = 0.05555555555555555
pulse_min_us = 1111
pulse_center_us = 1500
pulse_max_us = 2000
angle_min_deg = 20.0
angle_max_deg = 180.0
```

- `toggle_button` 是当前实测手柄的 pygame RB/R1 按键编号 10。
- `closed_position` 同时决定 GUI 滑块和 L3 的实时下限；输入多少度，软件下限和 RB 关闭角度就同步为多少。`open_position` 对应 RB 打开角度。
- GUI 控制条现在显示角度，不再显示百分比。

## 首次通电

为防止机构意外动作，首次通电前应保持：

```ini
output_enabled = false
```

确认舵机使用独立 7.4 V 电源、控制器与舵机电源共地，并拆除负载检查运动方向和机械限位后，才把它改成 `true`。该开关只启用 CH8 舵机，不会启用 CH0..CH7 推进器。

物理映射固定为 `0°..180° / 1000..2000 us`，GUI 的软件下限由 RB 关角度动态决定，上限始终为 `180°`。例如下限输入 `30°` 后，GUI、R3/L3、RB 和树莓派运行端都会按 `30°..180°` 工作。

## 树莓派端直接角度测试

`pi_runtime/servo_angle_test.py` 只测试 PCA9685 的 CH8，不启动 ROV 主控，也不会写入 CH0--CH7 推进器通道。脚本读取 `/etc/rov/config.ini` 的完整物理映射 `0..180°`；GUI 软件下限仍以 RB 关角度为准。真实测试前先停止主服务，并确认推进器断电/拆桨、舵机使用独立电源且共地：

```bash
sudo systemctl stop rov-usst.service
sudo apt install -y python3-smbus  # 尚未安装 smbus 时执行
sudo -u rov env ROV_CONFIG=/etc/rov/config.ini /opt/rov/usst/.venv/bin/python /opt/rov/usst/servo_angle_test.py --enable
```

确认提示输入 `ENABLE` 后，交互窗口直接输入角度数字，例如 `120`，程序会输出 `CH8 目标角度 120° -> 1667 us` 并发送对应 PWM。输入 `q` 退出并关闭 CH8 PWM。没有硬件时可用 `--dry-run` 验证换算，不会访问 I2C。
