# 飞智八爪鱼5 ROV手柄桥接

用途：绕过QGC只显示0–14号标准按键的限制，直接读取八爪鱼5厂商HID接口。

## 一键比赛入口

双击上级目录`比赛启动.bat`，打开QGC和小型状态窗，不再手动启动命令行桥接。
启动默认只监视/收遥测；状态窗内“开启手柄控制”在链路就绪、飞控上锁且输入归中时可用，
然后可单独勾选A键解锁许可。没有手柄时窗口持续等待，不退出。
普通QGC图标不会自动带起桥接。视频、树莓派部署和旧摄像头记录见上级`启动与摄像头说明.md`。
程序运行日志保存在`logs/competition.log`。一键入口、完整面板和命令行入口只能运行一个。

已确认的独立拓展键：

| 按键 | 原始位 | MAVLink按键编号 |
|---|---:|---:|
| M1 | `0x04` | 15 |
| M2 | `0x08` | 16 |
| M3 | `0x10` | 17 |
| M4 | `0x20` | 18 |
| LM | `0x40` | 19 |
| RM | `0x80` | 20 |

## 当前比赛配置

- 左摇杆：前后、左右平移
- RT/LT：连续线性上升/下潜，计算方式为 `RT-LT`
- 右摇杆：偏航和俯仰
- 横滚不分配人工输入；飞控在稳定模式下仍可自行稳定横滚

运动有两组独立档位，各为40%、100%，默认40%。左菜单（View）循环摇杆档位，
影响前后、左右平移、偏航和俯仰；右菜单（Menu）循环升潜档位，仅影响LT/RT。
两组都按`40→100→40%`循环；LB同时恢复两组到已保存的共同默认值（当前为40%）。
点击“默认运动档位设置 · LB复位”修改并保存默认值；保存不使当前档位跳变，按LB或下次启动时生效。
扳机死区3%，摇杆采用4%圆形死区和柔和正方向辅助：距离前后左右轴线8°内完全
消除串轴，8°至18°平滑过渡，超过18°保留完整斜向输入。

按键采用成对分配：A解锁、B上锁；RB在夹爪已保存的闭合/张开端点间快速切换；M3/M4按住时
夹爪慢开/慢合；AUX2是夹爪角度舵机，M1/M2按住时缓慢上调/下调；十字上/下控制云台上/下档，
十字左将云台设为可保存的快捷角度（默认-20°），十字右将AUX2上下舵机设为可保存的复位脉冲（默认920µs）；AUX3是末端旋转舵机，LM/RM按住时慢速逆时针/顺时针。
X开关定深、Y开关稳姿，可自由组合，启动两项关闭；当前固件支持独立定深22。
L3/R3留空。航向直接用飞控ATTITUDE.yaw，不做相对置零、积分或预测。
2026-10-04已实测校准陀螺仪并恢复INS_GYR_CAL=1；飞控上电先保持静止等待校准完成。
静止30秒航向变化从3.82°降低到0.15°，真实旋转停住与水下效果还需复测。
完整中文表见`比赛手柄最终配置.md`。

机械臂三路舵机由PC用`MAV_CMD_DO_SET_SERVO`直接控制，不再使用飞控Actuator按钮步进。
M1/M2、M3/M4、LM/RM按住时以约100µs/s连续变化，松手即停；面板显示当前目标PWM和
RB下一次动作。`SERVO9/10/11_FUNCTION`必须按随附参数文件设为Disabled，否则飞控会拒绝直接控制。
QGC显示Disabled只表示飞控不占用该输出，不表示舵机断电。比赛小窗口的“设置舵机实际范围”
可分别将夹爪开合、夹爪上下、末端旋转的实际最小/最大值保存在500～2500µs内；保存后立即生效。

QGC参数页面必须重新导入`C:\Users\15057\Documents\QGroundControl\Parameters\ROV比赛参数_最新版.params`。
项目目录内的`ardusub_button_profile.params`是同步备份；同目录下的
`ardusub_button_profile.param`仅作为Mission Planner格式备用。

云台上下档位为`-80/-45/-20/0/+20`度。十字左快捷角度和十字右上下舵机复位脉冲可在状态窗“十字快捷目标”中修改并保存，或编辑`controller_profile.json`中的`gimbal.quick_angle_deg`、`servos.angle.reset_pwm`；无需飞控烧录或重新导入参数。右键目标必须在上下舵机已设范围内；下一次按键才实际发送目标，不因修改配置自动动作。

## 安全监视

### 推进器启转测试

比赛状态窗口进入“推进器逐个测试”，现包含“逐个测试”和“运动启转”两页。
两页均点击一次启动、再点任一测试按钮停止；不是按住运行。切换电机/测试页、编辑PWM、
失焦、链路异常或命令拒绝停止输出，Esc或“停止测试并上锁”同时请求飞控上锁。
未收到上锁确认不能静默关闭。测试没有固定0.6秒时限，操作者必须遵守推进器实际测试条件。

- 单机可输入精确PWM，范围1000～2000µs；快捷5/10/15%仅用于填值。
- 前进、后退、上升、下降分别输入低侧1000～1500、高侧1500～2000µs。
  默认1490/1510仅供从中位附近开始查启转；不会自动开始测试。
- 整组测试读取实际`MOT_1_DIRECTION`～`MOT_8_DIRECTION`，结合Vectored 6DOF与物理
  MAIN映射分配PWM，不能按正/反桨分组猜方向。参数缺失/过期禁止整组启动，变化时停止上锁。
- 前后使用1～4号、升降使用5～8号，其余保持1500；显示每路目标与实测输出PWM。
  MAVLink逐路发送，不保证机械同时启转。此测试不包含姿态/深度闭环，不代表推力均衡。
- 测试前先上锁、停止手柄桥接控制并取消QGC Joystick Enable，固定机体于水中、清除异物；
  初次只在中位附近核对实际推水方向，异常立即停止。开启测试需人工确认并等待解锁回传。

### ROVMAKER推力资料边界

[ROVMAKER 2216官方手册](https://docs.rovmaker.cn/2216推进器产品手册.html)的标称值与
用户给出的24V正向2kgf、反向1.8kgf吻合，但尚未通过产品型号确认是同款。
手册规定1000～2000µs、1500中位，提供12V/16V/24V最大推力，不提供同一电压下完整
PWM—正反向推力曲线。因此90%仅能描述24V标称最大值之比，不足以作为全程PWM或推力补偿。
启转测试只能确定启转阈值，不能替代力传感器/拉力计的推力标定。
用户决定取消未经标定的90%试验补偿，保留现有正反桨、安装方向及转向映射。

- 正常手柄/姿态/定深：最新版参数恢复`MOT_PWM_MIN=1000`、`MOT_PWM_MAX=2000`，中位1500。
  正常运动指令没有额外推力比例修正，左右摇杆与扳机的独立操作增益保留。
- 单机与所有运动测试：输入PWM原值发送，不缩小高侧；测试面板不再提供试验补偿开关。
  例如输入2000输出2000，输入1600输出1600；实际输出仍应核对回传。
- 更新只涉及本地程序和参数文件，不自动连接或写入飞控，不启动电机、不部署树莓派。
  停止测试、上锁并断开推进器动力后重启比赛程序，再人工导入最新版参数、刷新并重启飞控，
  用参数回传核验1000/2000；仅更新本地文件不能证明实机已生效。
- 姿态与定深闭环继续由飞控处理，但不能保证逐台推力相等或无定位传感器时的水平定点。
  若水下测试出现明显偏转、漂移或饱和，仍需检查映射、机械干涉与推力差异，不能只提高PID。
- 原始1000/2000参数备份仍保留在
  `C:\Users\15057\Documents\QGroundControl\Parameters\ROV比赛参数_1000-2000_补偿前备份.params`。

[对应固件输出换算](https://github.com/ArduPilot/ardupilot/blob/dbe79216/libraries/AP_Motors/AP_Motors6DOF.cpp)
以1500为中位，分别采用`MOT_PWM_MIN/MAX`的上下行程；1000/2000提供两侧各500µs行程。

`MOT_PWM_MIN/MAX`在QGC Configure → Parameters搜索参数全名修改，控制推进器混控输出端点。
最新版参数文件为1000/2000，SERVO1～8也为1000/1500/2000；AUX舵机参数没有更改。
以1500中位计算，1100/2000两侧行程为400/500µs，不是已验证的90%推力补偿。

## 后续实机发送（现在不要执行）

开始实机测试前，必须先在QGC取消勾选Joystick的`Enable`，避免两套程序同时发送控制量。

```powershell
py .\rov_gamepad_bridge.py --send
```

即使使用`--send`，A键仍被屏蔽。只有最后完成全部无动力检查后，显式增加
`--allow-arm`才会放行A键。

不实现三路独立姿态锁。飞控负责标准姿态/深度闭环；PC从实际心跳确认模式，不能把按键
或请求发送成功当成定深成功。I²C深度计仍须验证驱动识别与水下数据。

本版必须配合更新后的`../pi_competition/rov_mavlink_bridge.py`：树莓派同时向QGC的14550
和控制面板的14551发送遥测。PC新参数`--telemetry-port`默认14551。代码尚未自动部署。
手柄超时或心跳过期会停止正常控制流；恢复时需全部输入归中0.5秒才允许恢复发送。
飞控的Pilot Control失控保护必须配置并实测。
GUI与命令行入口只能运行一个；不能与QGC手柄同时控制。

档位表示操纵增益，不是电机功率或实测速度上限。GUI云台角度为目标值，非实际角度反馈。
无水平定位时不能自动定点。完整部署顺序、最终键位与验收边界见`比赛手柄最终配置.md`。
