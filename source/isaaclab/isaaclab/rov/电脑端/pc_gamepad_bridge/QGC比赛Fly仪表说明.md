# QGC Fly 比赛仪表

仪表安装本身是电脑桥接与 QGC 显示更新，不修改飞控控制器、不写推进器参数、不改变手柄方向。基于本机 QGC 5.1.4 的 `FlyView.instrumentQmlFile2` 外部 QML 加载入口；不替换 QGC 程序或安装目录里的文件。本轮独立模式固件的烧录结果另见 `firmware/烧录结果_20261004_独立定深与紧凑仪表.md`。

## 怎么启用

1. 先按 B，并确认飞控已上锁；在桥接面板停止控制。不要为了安装显示而断开正在工作的控制链。
2. 正常退出 QGC。桥接窗口也关闭，然后双击本项目根目录的 `启用QGC比赛仪表.bat`。QGC 若仍在运行，脚本拒绝修改。
3. 再运行原来的 `比赛启动.bat`。Fly 右下角保留QGC原生圆形罗盘，紧挨其左侧加载中文比赛状态卡；旁边原生数值栏只保留“解锁计时”。
4. 仍按原流程在桥接面板开启手柄控制、确认归中并按需要允许 A 解锁。比赛中可以最小化桥接窗口，只看 QGC Fly；**不能关闭桥接窗口**，QGC 本身不能替代自定义手柄桥接。

2026-10-04 已在 QGC 正常退出后执行安装，并保留配置备份。重开比赛启动后首次发 Fly 整页截图，确认实际 QGC 中的位置、中文和数据；安装配置不代表实车验收。

比赛卡为约 400×105 像素的紧凑布局：左半航行、右半操作，背景约 60% 不透明（40% 透明）。正常时不显示标题或长说明，只有告警才增加最多两行。QGC原生圆形罗盘位于最右侧，比赛卡与它底部对齐，中间留12像素及原生姿态环所需空间；详细 PWM、升降速度和说明仍在独立状态窗口。

## 比赛保留的信息

| 显示 | 数据含义与来源 |
|---|---|
| 深度估计 | 飞控 `GLOBAL_POSITION_INT.relative_alt` 毫米值取负换成米，向水下为正。不是 GPS 海拔；水面零点和外置压力深度计仍须校验。没有外置深度计时 ArduSub 也可能报 0，**0 不能证明深度计可用**。 |
| X 定深、Y 定姿态 | 根据飞控新鲜 HEARTBEAT 的真实模式显示，等待切换确认期间不提前改灯。上锁时为模式选定，不代表推进器正在闭环工作。 |
| 上锁／解锁、手柄和控制流 | 区分仅监视、等待归中、发送中、输入超时；显示 A 解锁是否允许。 |
| 横滚、俯仰、航向 | 飞控真实ATTITUDE回传，航向为yaw弧度转度后归一到0～360°，不叠加相对/连续偏航、不按角速度预测或积分。2026-10-04逐样本原始/显示对照误差0，181项回归通过。 |
| RB 下一次 | 直接读取桥接现有夹爪状态机的下一次动作，慢开／慢合之后自动跟随更新。是下次发出的命令，不是夹爪实际位置。 |
| 夹爪命令／输出 PWM（详细窗口） | 分开显示软件目标与飞控 SERVO_OUTPUT_RAW 的输出脉宽；输出 PWM 也不是机械角度或实际夹紧力。紧凑 Fly 卡仅保留 RB 下一次动作。 |
| 摇杆／升降操纵增益 | 本地两组独立增益设置值，非推进器功率上限或实时推力。 |
| 云台目标 | 手柄离散角度的目标设置，非角度传感器实测。仅监视时改变的是预选值，不会控制云台。 |
| 电压、电流 | 飞控电池遥测；优先 BATTERY_STATUS 主电池，再 SYS_STATUS。未接电流计／未配置时显示未知，不用 PWM 估算电流。 |
| 升降速度（详细窗口） | GLOBAL_POSITION_INT.vz 换算成 m/s，向下为正；飞控估计值而非测速仪实测。紧凑 Fly 卡不重复显示。 |
| Pi 温度、Pi/PC 内存、网口发送与占用 | 前一版只读资源监测的新鲜数值，占用率为双工单向峰值／协商速率，并非纯视频码率或应用帧率。 |
| 关键告警 | 飞控严重 STATUSTEXT、漏水传感器异常、手柄超时、模式切换失败／等待、推进器测试页面打开、Pi 过热。QGC 顶部原生告警仍保留，不能用本卡替代。 |
| 解锁计时 | QGC 原生 FlightTime，不是整场比赛倒计时；多次解锁的语义遵循 QGC。 |

删除数值栏中的无水下定位来源的地速、返航距离、GCS 距离等默认航空项目，避免把岸上零值当成水下运动实测。

## 定深／定姿态组合的版本边界

Manual19：两关；Stabilize0：仅定姿态；DepthHold2：定深加定姿态。
私有 DepthOnly22 已于2026-10-04晚间烧录，并由真实飞控回传确认。只有飞控同时回传 `ROV_DONLY=1` 才把 22 解释为仅定深；旧固件不支持的组合，现有桥接仍会拒绝，显示层不会伪造它已开启。仪表启用只需一次，之后每次使用只开“比赛启动”；正常退出QGC会保存外部仪表设置。

## 原生 QGC 数值栏手动设置

Fly 页面右键点击原来的数字区域 → 解锁编辑 → 点某个数值选择数据源和名称；用 +/− 增删行列 → 点锁图标保存。官方说明：
https://docs.qgroundcontrol.com/master/en/qgc-user-guide/fly_view/instrument_panel.html

原生数值编辑器不能凭空新增“RB 下一次”等自定义文字状态。本次安装脚本负责外部比赛仪表与原生解锁计时的一次性配置；不需要在下拉列表里寻找不存在的夹爪项目。右键比赛卡出现的是 QGC 自带的仪表样式菜单，选内置样式会替换比赛卡；想换回来可退出 QGC 后再次运行启用脚本。

## 只读显示链与过期保护

桥接现有遥测和本地状态 → 每 200ms 发布只读快照 → `127.0.0.1:18765/status` → QGC 外部 QML 每 200ms 读取。

不占用 QGC 的 14550 或桥接的 14551，不增加串口所有者，也不把自定义状态假冒为飞控遥测。HTTP 仅监听本机回环、只支持 GET、校验 Host、无解锁/舵机/模式控制入口。控制线程不等待 HTTP；HTTP 线程不操作 Tk 或控制器。

控制线程停止更新超过 1s，服务立即报过期；QML 未成功读取超过 1.5s 时整卡变未知。飞控心跳、深度、PWM、电流各有最多 3s 有效期，姿态为 1s；Pi 资源为 3s。QGC 当前车辆 ID 必须与快照一致，否则不得显示该机器人数据。

本卡不能证明：外置深度传感器已校准、输出 PWM 已让舵机到位、视频延迟已测定、闭环参数水下鲁棒性已验收。
