- 本机 2026-10-21 默认命令行 `python/pythonw` 指向 Python 3.8.15，与现用代码不兼容。接收电脑需 Python 3.10+，安装 `电脑端/pc_gamepad_bridge/requirements.txt` 后运行离线检查和测试；不能因为附了代码就宣称开箱即用。
