# 前视声纳水下目标跟踪方案设计
## 基于信念状态DRL + 卡尔曼滤波 + SAC 的 1-DoF 声纳跟踪系统

---

## 1. 问题定义

| 参数 | 描述 |
|---|---|
| 传感器 | 前视声纳（Fwd-Look Sonar），单目声纳图像 |
| 自由度 | 1-DoF，仅绕 Z 轴旋转（偏航角 θ ∈ [-180°, +180°]） |
| 帧率 | 5–15 Hz（远低于光学相机） |
| 观测噪声 | 多径、混响、斑点噪声，信噪比低 |
| 目标 | 水下移动目标（AUV/ROV/鱼类/结构物） |
| 核心难点 | 部分可观测、低帧率、高噪声、无色彩纹理 |

## 3. 详细模块设计

### 3.1 模块 A：声纳图像预处理

**输入**：原始声纳图像 I_t（512×512 或 960×720 灰度图）
**输出**：预处理图 I'_t

```python
def preprocess_sonar(I_raw):
    # 1. 自适应增益归一化（声纳强度范围变化大）
    I_norm = adaptive_histogram_equalization(I_raw, clip_limit=2.0)

    # 2. 斑点噪声滤波（声纳特有乘性噪声）
    I_median = cv2.medianBlur(I_norm, ksize=3)
    I_bilateral = cv2.bilateralFilter(I_median, d=5, sigmaColor=30, sigmaSpace=10)

    # 3. 水下环境自适应阈值（去除远场噪点）
    I_thresh = adaptive_threshold(I_bilateral, block_size=31, C=5)

    return I_thresh
```

**文献依据**：KARL (Boyalakuntla 2025) 使用了噪声滤波 + 状态估计的预处理流水线。

### 3.2 模块 B：轻量目标检测

**输入**：预处理图 I'_t
**输出**：观测 z_t = [a_t, r_t, c_t]

```python
class SonarDetector:
    def __init__(self):
        # YOLOv8-nano: 速度优先，~1.5M参数
        self.model = YOLO("yolov8n.pt")  # 需要在水下声纳数据集上微调
        self.target_classes = ["AUV", "diver", "fish", "structure"]

    def detect(self, I):
        results = self.model(I, conf=0.3, iou=0.5)
        dets = results[0].boxes
        if len(dets) > 0:
            # 取最高置信度目标
            best = dets[0]
            # 声纳极坐标转换：像素(x,y) → 方位角a + 距离r
            a, r = pixel_to_polar(best.xyxy[0], I.shape)
            c = best.conf[0].item()
            return {"azimuth": a, "range": r, "confidence": c}
        return None  # 未检测到目标
```

**关键问题**：声纳数据集稀缺。解决方案：
- 使用预训练模型在光学图像上预训练，迁移到少量标注声纳数据
- 用仿真数据（COLA2 + Gazebo 生成声纳图像）扩展训练集

### 3.3 模块 C：卡尔曼滤波信念估计（核心）

**POMDP 框架**，参考 PyroTrack (Khoshdel 2024)：

```
状态空间：x_t = [px_t, py_t, vx_t, vy_t]^T    ← 世界坐标位置+速度
观测空间：z_t = [a_t, r_t]^T                    ← 声纳极坐标方位角+距离
控制输入：u_t = [Δθ_t]                          ← 声纳旋转
```

**状态方程**（匀速 + 声纳运动补偿）：

```
x_{t|t-1} = F · x_{t-1} + B · u_t + w_t

其中:
F = [1 0 dt 0; 0 1 0 dt; 0 0 1 0; 0 0 0 1]    ← 匀速运动
B = 声纳姿态到世界坐标的雅可比矩阵                 ← 声纳旋转补偿
w_t ~ N(0, Q)                                    ← 过程噪声
```

**观测方程**（声纳极坐标到笛卡尔坐标转换）：

```
z_t = h(x_t) + v_t

h(x_t) = [atan2(py - sonar_y, px - sonar_x),    ← 方位角
          sqrt((px - sonar_x)^2 + (py - sonar_y)^2)]  ← 距离
v_t ~ N(0, R_t)                                   ← 观测噪声，随距离增大
```

**观测噪声模型**（关键设计 - 声纳特性）：

```python
def observation_noise(target_range):
    """
    声纳观测噪声与距离成正比
    近场(~5m): σ_r = 0.1m, σ_a = 1°
    远场(~50m): σ_r = 2.0m, σ_a = 10°
    """
    sigma_r = 0.02 * target_range + 0.05       # 距离噪声
    sigma_a = np.deg2rad(0.15 * target_range + 0.5)  # 角度噪声
    R = np.diag([sigma_a**2, sigma_r**2])
    return R
```

**信念更新流程**：

```python
class BeliefEstimator:
    def __init__(self):
        # 扩展卡尔曼滤波 (EKF) — 因为观测方程非线性
        self.kf = ExtendedKalmanFilter(dim_x=4, dim_z=2)

    def predict(self, dt):
        """预测步：匀速运动 + 声纳运动补偿"""
        F = np.array([[1,0,dt,0],[0,1,0,dt],[0,0,1,0],[0,0,0,1]])
        self.kf.F = F
        self.kf.predict()

    def update(self, z_t, sonar_pose):
        """更新步：仅当检测置信度 > 阈值时"""
        if z_t is None or z_t["confidence"] < CONF_THRESH:
            # 无观测：只预测，增大不确定性
            self.kf.Q *= 1.05  # 不确定性逐渐增大
            return self.kf.x, self.kf.P

        # 构建观测向量
        z = np.array([z_t["azimuth"], z_t["range"]])
        R = observation_noise(z_t["range"])

        # EKF 更新
        self.kf.R = R
        self.kf.update(z, HJacobian=self._hJacobian, Hx=self._hx)

        # 检测到目标 → 重置不确定性
        self.kf.Q = np.eye(4) * 0.01

        # 信念 = 后验均值 + 协方差
        return self.kf.x, self.kf.P

    @property
    def belief(self):
        """信念状态：均值 + 不确定性"""
        return self.kf.x, self.kf.P
```

### 3.4 模块 D：声纳特征编码器

```python
class SonarFeatureEncoder(nn.Module):
    """轻量CNN将声纳图像编码为特征向量"""
    def __init__(self):
        super().__init__()
        # EfficientNet-B0 backbone (轻量，~4M参数)
        self.backbone = efficientnet_b0(pretrained=True)
        self.backbone.features[0][0] = nn.Conv2d(1, 32, 3, 2, 1)  # 单通道输入

    def forward(self, sonar_frames, sonar_angle):
        """
        sonar_frames: [B, N, 1, H, W]  ← N帧声纳历史
        sonar_angle: [B, 1]            ← 当前声纳朝向
        """
        B, N = sonar_frames.shape[:2]
        # 逐帧编码
        features = [self.backbone(sonar_frames[:, i]) for i in range(N)]
        feat_stack = torch.stack(features, dim=1)  # [B, N, C]
        # 时序聚合
        feat_agg = feat_stack.mean(dim=1)  # 平均池化
        # 融合声纳朝向
        out = torch.cat([feat_agg, sonar_angle], dim=-1)
        return out  # [B, C+1]
```

### 3.5 模块 E：DRL 控制器（SAC）

**状态空间设计**：

```
s_t = [
    μ_px, μ_py,           ← 目标位置信念均值（来自KF）
    σ_px, σ_py,           ← 目标位置信念不确定性（来自KF）
    θ_t,                   ← 当前声纳朝向
    f_t (256-dim),         ← 声纳图像特征（来自CNN编码器）
    v_target_est           ← 目标速度估计值（来自KF）
]
总和：~262维（256来自特征 + 6维结构化状态）
```

**动作空间**：

```
a_t = [Δθ]  ∈ [-30°, +30°]   ← 声纳旋转角度增量（连续）
```

**奖励函数设计**（多层次，参考 CSAOT + HDRL）：

```python
def compute_reward(belief, det_result, action, prev_belief):
    """
    多目标奖励函数
    """
    mu, sigma = belief
    prev_mu, prev_sigma = prev_belief

    # 1. 跟踪维持奖励：目标位置不确定性越小越好
    r_track = -0.1 * (sigma[0,0] + sigma[1,1])  # 协方差迹的负值

    # 2. 检测置信度奖励
    if det_result is not None:
        r_detect = 1.0 * det_result["confidence"]
    else:
        r_detect = -0.5  # 丢失目标的惩罚

    # 3. 搜索效率奖励：鼓励声纳找到目标
    #    当目标丢失时，如果搜索动作最终找回了目标 → 正奖励
    track_lost = (sigma[0,0] + sigma[1,1]) > LOST_THRESH
    track_regained = (prev_sigma[0,0] + prev_sigma[1,1]) > LOST_THRESH and \
                     (sigma[0,0] + sigma[1,1]) <= LOST_THRESH
    if track_regained:
        r_reacquire = 5.0  # 重捕获大奖励
    else:
        r_reacquire = 0.0

    # 4. 动作平滑奖励：避免剧烈摆动
    r_smooth = -0.01 * (action ** 2)

    # 5. 边界惩罚：声纳不要频繁转到极端角度
    r_bound = -0.01 * max(0, abs(angle) - 150)  # 超过±150°时惩罚

    r_total = r_track + r_detect + r_reacquire + r_smooth + r_bound
    return r_total
```

**SAC 算法配置**：

```python
class SACConfig:
    # 网络架构
    actor_hidden = [256, 256]           # Actor 网络隐层
    critic_hidden = [256, 256]          # Critic 网络隐层

    # SAC 超参数
    lr = 3e-4                           # 学习率
    gamma = 0.95                        # 折扣因子（低帧率取较小值）
    tau = 0.005                         # 软更新系数
    alpha = 0.2                         # 初始熵正则系数
    autotune_alpha = True               # 自动调节 α

    # 经验回放
    buffer_size = 500_000               # 经验池大小
    batch_size = 256
    start_steps = 10000                 # 随机探索步数

    # 训练
    total_steps = 1_000_000
    updates_per_step = 1

    # 声纳特定
    dt = 0.1                            # 控制周期 (10Hz)
    max_dtheta = 0.52                   # 最大旋转增量 (30°)
    reward_scale = 1.0
```

**网络结构**：

```python
class Actor(nn.Module):
    """SAC 策略网络：状态→动作"""
    def __init__(self, state_dim, action_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(state_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
        )
        self.mean = nn.Linear(256, action_dim)
        self.log_std = nn.Linear(256, action_dim)

    def forward(self, state):
        x = self.net(state)
        mean = self.mean(x)
        log_std = torch.clamp(self.log_std(x), -20, 2)
        std = log_std.exp()
        return mean, std

    def sample(self, state):
        mean, std = self.forward(state)
        normal = Normal(mean, std)
        action = normal.rsample()  # 重参数化采样
        action = torch.tanh(action) * MAX_DTHETA  # 缩放到[-30°,+30°]
        log_prob = normal.log_prob(action).sum(-1)
        return action, log_prob


class Critic(nn.Module):
    """SAC Q 网络：状态+动作→Q值"""
    def __init__(self, state_dim, action_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(state_dim + action_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 1),
        )

    def forward(self, state, action):
        return self.net(torch.cat([state, action], dim=-1))
```

## 4. 训练策略

### 4.1 仿真训练（Phase 1）

**仿真平台**：Stonefish Simulator + ROS2

```yaml
# 仿真场景配置
scene:
  water: { visibility_range: 5-20m, turbidity: "low/medium/high" }
  sonar: { type: "imaging_sonar", fov: 120°, range: 50m, noise_model: "realistic" }
  target:
    type: "AUV"
    motion: { random_waypoints + 轻微规避 }
  noise:
    - 多径回波
    - 混响噪声
    - 随机缺失帧(丢包率10-30%)
```

**训练流程**：

```
Step 1: 随机探索 (10000 steps)
        → 声纳随机旋转，收集初始经验

Step 2: SAC 训练 (1M steps)
        → 每 episode 500步 (50秒真实时间)
        → 目标随机初始化，随机运动轨迹
        → 评价指标：跟踪成功率, RMSE, 丢失恢复时间

Step 3: Domain Randomization (500K steps)
        → 随机化：噪声水平、能见度、目标速度、声纳帧率
        → 提升策略鲁棒性
```

### 4.2 Sim2Real 迁移（Phase 2）

基于 **AOT (Luo 2018/19)** 的迁移策略：

```python
# 域随机化参数范围
```

### 4.3 在线微调（Phase 3）

使用真实声纳数据微调：
- 冻结 KF 和特征编码器骨干网络
- 仅微调 SAC 策略网络最后一层
- 使用安全边界：在仿真中验证后再部署到真实环境

## 7. 风险与缓解

| 风险 | 缓解措施 |
|---|---|
| 声纳训练数据不足 | 仿真数据 + 域随机化 + 少量真实数据微调 |
| Sim2Real 差距大 | 渐进式迁移：仿真→水箱→湖试→海试 |
| 目标检测在声纳图上不可靠 | KF 提供无观测时的鲁棒预测；检测置信度门槛自适应 |
| 1-DoF 物理限制 | 奖励函数引导声纳停留在目标可能区域；搜索策略使用 ε-greedy |
| 实时性要求 | 模型量化 + TensorRT + 特征编码器剪枝 |
