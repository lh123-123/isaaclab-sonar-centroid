01

Direct 环境 · DirectRLEnv 实现

source/.../direct/isaac_auv_tracking/

D核心环境文件

文件负责的任务
auv_tracking_v7_flow_hover_gsrov_env.pyv7 主实现DirectRLEnv 子类：全局光流零化悬停；搭建场景（立方体代理刚体、相机、纹理平面、池壁、参考球）、光流/纹理缓冲、观测、奖励、终止、重置、动作→PID；Farneback/RAFT 流估计。
auv_tracking_env.py基类AUVTrackingEnv / AUVTrackingEnvCfg：目标追踪基环境（ sonar/KF/目标运动/洋流/奖励/终止），v7 继承其动力学与 PID 装配。
__init__.pyGym 任务注册表：注册 `Isaac-AUV-Tracking-Direct-v7-flow-hover` 与 `...-gsrov`，绑定 cfg 与 SB3 yaml。

H动力学 / 控制 / 流体

文件负责的任务
batch_pid.pyBatchPIDController：[surge,sway,yaw]+深度/姿态→8 PWM；warpauv6 与 gsrov8 两套分配；kp/ki/kd、伪逆矩阵。
thruster_dynamics.pyGSROV_THRUSTERS 几何、8 推进器位置/朝向、GSROV_ACTION_TO_MAIN 通道映射、DynamicsFirstOrder 一阶滞后、ConversionFunction 推力曲线。
rigid_body_hydrodynamics.py浮力/拖曳力矩计算（water_rho/water_beta），供 _compute_dynamics 调用。
ocean_current.pycreate_ocean_current_field：uniform/vortex/sine_wave/random 四种流场，时间调制、裁剪。
batch_lqr.pyHoloOcean 风格目标运动（RRT+LQR），用于 v0/v1/v4 等追踪任务。

P感知 / 测量 / KF / 流

文件负责的任务
cam_meas.py相机 (r,α) 测量：由 GT 目标位置生成 bearing/range，含噪声与 KF 先验门。
sonar_meas.py声纳 (r,α) 测量：极坐标峰值检测、belief 门控、冷启动。
kalman_filter_batch.py批量 KF/EKF 目标状态估计（GPU）。
flow_obs.pyDirect-v2 堆叠极坐标残差 + 质心位移。
sparse_flow.py稀疏金字塔 Lucas-Kanade（v4 光流 3 维向量）。
teach_match.py基于颜色模板的 teach 图像匹配（NCC）。

Manager-based 实现 · manager_based/isaac_auv_tracking/v7_flow_hover/

行为等价移植
文件负责的任务
v7_flow_hover_env_cfg.pyManagerBasedRLEnvCfg：场景/观测/动作/奖励/终止/事件的声明式配置；GS-ROV 物理常数；奖励权重按 dt 修正。

mdp/rewards.pyflow_nulling / alive / depth_hold / attitude_hold / action_smoothness。
mdp/terminations.pytexture_lost / depth_exceeded / attitude_exceeded / out_of_bounds / reset_auv_buffers。
mdp/__init__.py导出 actions/observations/rewards/terminations 子模块。
__init__.pyManager-based 任务注册。

Agents / 网络 · direct/.../agents/

SAC 策略、编码器、流估计
文件负责的任务

flow_vec_encoder.pyDirect-v6：预结构化 6 维 flow 向量编码器（无卷积）。
sonar_encoder.pySonar 极坐标图像 encoder（ResNet50）供 v1 非对称 SAC。
play_metrics.py回合级 play 指标（numpy）。
rsl_rl_ppo_cfg.pyRSL-RL PPO 配置。
drqv2/*DrQ-v2 代理（agent/frame_stack/replay_buffer/utils）供 v1 声纳任务。
