✎任务定义

v7 用一台朝前、正立无 180° 翻转的相机观察前方 4×4 m 的纹理平面（固定在地面坐标系）。 图像光流为零 ⇔ 相机相对地面静止，所以「驱动光流到零」等价于「在地面系定点悬停」。

在有洋流时，光流观测（du/dv）告诉策略水流方向，而奖励被重塑为「静止（锁定地面）得高奖励、随流漂移不得分」。 于是策略学会持续逆流推进直到净位移消失——完全由光流线索驱动的「顶流悬停」目标。

注：v7 统一由 GS-ROV 8 推进器版本（auv_tracking_v7_flow_hover_gsrov_env.py）承接训练，旧 WarpAUV/RAFT 实现已删除。

网络结构 · Actor / Critic

⧉非对称结构数据流

图像分支 (Actor) 状态分支 (Critic) 特征 / 输出 动作

AActor — MidCNNExtractor + π

输入image (7,64,64)
第一层卷积Conv2d(7→32, k5,s2)
Conv 堆叠32→64→64→128→128
下采样64→32→16→16→8→8
头部GAP(128) ⊕ Softmax(2×128)=384
TrunkLinear→256 · LayerNorm · Tanh
策略 MLP (pi)[256, 256]
输出tanh-Gaussian, 3-D 动作

CCritic — StateCritic (Q)

输入state (9) ⊕ action (3)
回路数2 个独立 Q 网络 (n_critics=2)
MLP (qf)[256, 256]
输出Q(s,a) 标量
图像输入✕ 不使用（只看状态）
特征共享share_features_extractor = False

非对称设计的理由：Critic 拿干净的 9 维真值状态做稳定的价值估计，Actor 被迫只从像素+光流中提取制导信息（"往哪走 / 左还是右"）。

⟡空间 Softmax 头（为何不全局平均池化）

CNN 最后一层保持 8×8 空间图。头部发射 concat(GAP, spatial-softmax)：

  • GAP (C) → "有没有东西、有多大"（外观 / 视距），平移不变。
  • soft-argmax (2C) → "它在哪"（方位），平移等变——把证据移动一格，预测坐标随之移动。

实测：纯 GAP 在合成图上横扫 blob 相对输出变化 ≈0.0000（完全左右镜像对称，方位信息丢失）；加 soft-argmax 后跨度达 1.43。约 0.3M 参数 / ~30M MACs，远轻于 ResNet18（11.2M / 161M）。

▦纹理掩码与流 RMS

# 纹理掩码：灰度梯度幅值阈值 + 最大池化下采样 grad = |∇gray|, hot = (grad > 8.0) mask = adaptive_max_pool2d(hot, 64×64) present = (texture_count ≥ 20) # 流 RMS：在纹理像素上统计（纹理不足则用全图） rms = sqrt( Σ(|flow|²·mask) / Σ mask ) flow_rms_n = clamp(rms / 64, 0, 1) # 送奖励与状态 # 纹理丢失连续 50 步 → 终止

OpenCL 下 Farneback 在 RTX 3090 上较纯 CPU 快 ~3.5×，与 CPU 结果差 <1e-3 px。

奖励设计 · Reward Design

★奖励权重与高斯整形

flow_term (光流零化) depth_term (深度保持) att_term (姿态保持) 动作平滑惩罚

f奖励公式

r = 1.0 · flow_term + 0.3 · alive + 0.1 · depth_term + 0.1 · att_term − 0.01 · smooth flow_term = present · exp(−flow_rms_n² / σ_flow²) depth_term = exp(−depth_err² / σ_depth²) att_term = exp(−att_err² / σ_att²) smooth = Σ (aₜ − aₜ₋₁)² # 3 维 alive = present

σ参数与语义

rew_flow1.0 主项
rew_alive0.3
rew_depth0.1
rew_att0.1
rew_action0.01
σ_flow0.05
σ_depth1.5 m
σ_att0.3 rad

姿态误差相对自由浮动配平（-20° 抬头）测量，而非水平——保持自然配平才是物理上正确的「无漂移」姿态。σ_flow=0.05 由实测流 RMS 标定（≈0.047）。
